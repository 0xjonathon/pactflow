# Product journey review — 2026-10-09

Product-owner feedback: demand publication could not be found, while the visible creation flow required a partner wallet before any matching. A Brief and a Pact have different purposes. A Brief describes proposed work and attracts applications; a Pact binds agreed parties, evidence, verification, deadlines and settlement after selection. Publishing a Brief must neither create an escrow nor claim funds are secured.

## Scope and evidence

Retain Next.js/Fastify/Drizzle and the existing V1/V2 contracts, evidence permissions, settlement history, Google/guest choice and mandatory wallet verification for protected actions. Verify first-time public navigation, both complete requester/partner paths, interruption recovery, role permissions, expired terms, English/Chinese, mobile and accessibility. Keep manual/deterministic real local flow evidence separate from mocked Google and unavailable external providers.

This review does not remove production gates: real PostgreSQL/Redis, private storage/scanner, isolated worker, live Envio, configured provider/Google login, public V2 deployment, server/domain/TLS and independent public smoke remain required. No public-ready claim is permitted on local browser evidence alone.

## Executed acceptance

- Final fixed optimized Web build: **22/22 browser cases PASS in 3.3 minutes**. Both locales begin from public home → Publish Brief; the first-time case chooses guest access and verifies a real local wallet signature. Publication needs neither a partner address nor a website/manual-approval URL, and the wallet transaction nonce remains unchanged.
- Interrupted publication resumes the same owner-only draft from My Work. API-created JSON rules survive UI resumption unchanged. Unavailable semantic options remain disabled according to the actual capability object.
- Marketplace cases publish, search, apply, choose, confirm auto-filled worker and configurable 12-hour review/three revisions, fund, accept, revise, resubmit, manually approve, settle and mutually disclose a redacted receipt. English recovery interrupts spec saving after onchain creation, refreshes and funds **the same escrow with the original terms**.
- Automatic V2 cases also exercise failed signed checks, revision, exact worker balance increase, real activity/reputation, private report denial and mutual disclosure.
- **36 application tests: 34 PASS / 2 SKIP**. Extended API assertions cover idempotent draft identity/ownership, immutable publication retries, positive bounded terms, withdrawn reapplication, duplicate pending prevention, expiry and closure after linking. Real PostgreSQL/Redis skips remain blockers.
- Eleven routes × two viewports × two locales: **44 WCAG automated audits, zero violations**. Twelve routes × seven specified widths × both locales: **168 viewport checks**; keyboard tabs, reduced motion, empty/unauthorized social preview and page-error checks pass. Types for scripts/all ten packages, lint, formatting and optimized production Web build pass. Contract source remains unchanged in this update.
- Earlier acceptance exposed recommendation badge button naming, inline/footer link styling and test locator assumptions about option disabling/address casing. These were corrected and verified. One run's trace archive failed because the test source was edited during execution; final acceptance ran on fixed files and supersedes that failed run. No failed case is counted as a pass.
