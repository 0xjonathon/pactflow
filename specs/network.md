# Network

/network preserves the talent discovery surface with real profile search, skill/category/min-completed filters and pagination. Declared skills are distinct from verified outcomes.

Profiles and completed relationships link to Work Passports. No fictional Agent records or opaque trust scores are generated. Search and category/skill controls have accessible names; empty results are explicit.

## Acceptance and boundaries

Agent identity, verifier discovery registry UI and interactive Work Graph are P1 and remain disabled until all P0 gates pass.

Required acceptance: actual user flow, English/Chinese, keyboard and mobile, empty/loading/failure states. Executed gates and evidence are recorded in `qa/PRODUCTION_AUDIT.md`; full source requirements are in `product/MASTER_DIRECTIVE.md`.
