# Proof

/proof displays actual chain/network, V1/V2 configured addresses, index source/freshness and configured release commit/repository. Missing V2 or metadata is explicitly unavailable. /p/[publicId] shows approved work receipt, settlement evidence and report links.

Local chain is labelled LOCAL_TEST_ONLY, including transaction/address links. V1 records are preserved; public V2 records are created only by verified deployment scripts. Receipt metadata/OG image fetch only the approved public projection and return 404 without both parties.

## Acceptance and boundaries

Public repository URL/release commit, actual V2 addresses, live GraphQL and fresh-browser HTTPS smoke require operator configuration. Local chain receipts cannot stand in for testnet receipts.

Required acceptance: actual user flow, English/Chinese, keyboard and mobile, empty/loading/failure states. Executed gates and evidence are recorded in `qa/PRODUCTION_AUDIT.md`; full source requirements are in `product/MASTER_DIRECTIVE.md`.
