# 从需求到合作协议

需求和合作协议是两个阶段。

**还没有合作伙伴：** 首页或右上角选择「发布需求」。描述目标、预算、交付期限、验收方式与保证金安排即可发布，不需要填写合作方地址，也不会发起资金交易。需求出现在「发现」中，交付方连接并验证钱包后提交合作提案。你比较资料和提案，选择一位合作伙伴，再进入「确认合作内容」。系统自动带入这位伙伴已经验证的钱包，作为收款账户。

**已经谈妥合作：** 在首页、流程说明或「我的工作」选择「与已有伙伴创建协议」，跳过找人阶段。此时需要填写对方的收款钱包。

## 谁参与合作

- 委托方发布需求，确认预算并锁定资金；界面显示你当前连接的钱包。
- 交付方完成工作、提交证据，通过验收后获得里程碑报酬。合作伙伴就是选定的交付方。
- 争议处理方是双方认可的第三方，处理验收或付款争议，其钱包不能与双方相同。平台配置的默认地址仍需双方确认；不能把自己的地址填在这里。

## 何时支付

发布需求和选择合作伙伴都不锁定资金。确认协议页展示收款方、每个里程碑的金额和期限、验收方式、双方保证金、接受截止时间、验收时长、修订次数和争议处理方。委托方确认后用钱包创建、授权和锁定协议款项及自身保证金。交付方查看固定条款并接受已锁定资金的协议，才开始履约。

交付方提交约定证据。本人验收适合设计、研究、内容及通用工作；自动验证适合有确定检查规则的工作；需要 AI 的语义规则只在真实服务可用时提供。未通过验收时按协议修订，默认首次提交后最多两次修订。服务故障不会签发通过证明，也不消耗修订次数。通过后按里程碑结算，形成真实活动、信誉和工作收据。公开收据需要双方授权，不会自动公开私有证据。

## 失败后如何继续

「我的工作」分别展示「我发布的需求」和「我的申请」。发布失败后已保存的需求显示为草稿，选择「继续编辑草稿」即可恢复；重试使用相同需求身份。已签协议按委托方或交付方身份提示锁定资金、接受、交付、验收或修订。

协议创建成功但保存、授权或资金操作失败时，确认页保留原协议与固定条款，继续原流程，不重新创建。若浏览器丢失本地资料且服务端尚未保存协议详情，页面明确提示恢复失败，并阻止用重新生成的条款继续操作。已关联协议的需求不能通过关闭需求来取消协议，取消或争议需要进入协议工作台。
