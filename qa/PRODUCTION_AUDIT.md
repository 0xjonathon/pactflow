## Reproducible local run

`pnpm local:deploy` against loopback Anvil, then `pnpm local:services --production-web`, then `pnpm test:e2e:local`: **8/8 passed in 2.9 minutes** on the fixed optimized production Web build. Node holds ephemeral wallet keys; browser sees only addresses/provider bridge. Evidence JSON/PNG has no private keys. `.local` databases/accounts/env/logs are ignored and excluded from CI artifacts.

Earlier development-only viewport run reported a transient script syntax error while files were being changed. Fixed-build acceptance subsequently passed both languages with no page errors. The local production harness initially inherited development NODE_ENV; it now explicitly builds/starts Web in production while its API/local-chain mode remains development. Axe found primary-button contrast and an unnamed talent selector; both were corrected and rechecked. These earlier failures are not hidden or counted as passes.

## Open operational limits

A durable attestation recovery retries the same signed raw transaction while its result is uncertain. A definitively reverted/expired transaction stays ERROR; it is never reinterpreted as a failed submission or a passing proof. Long-outage/expiry recovery, external nonce contention and restore interruption must be exercised on the production worker before release. Ordinary contract deadline/dispute paths remain available; no unilateral refund or silent signing replacement was added.

Production Envio must provide a canonical live endpoint and a correct finalized cursor. Local RPC acceptance is explicitly `LOCAL_TEST_ONLY`; it does not close this gate. A clean checkout or green build does not close missing runtime gates. Do not announce production availability or begin gated P1 on the strength of this audit.
