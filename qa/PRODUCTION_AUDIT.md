## Reproducible local run

`pnpm local:deploy` against loopback Anvil, then `pnpm local:services --production-web`, then `pnpm test:e2e:local`: **20/20 passed in 3.1 minutes** on the fixed optimized production Web build. Node holds ephemeral wallet keys; browser sees only addresses/provider bridge. Evidence JSON/PNG has no private keys. `.local` databases/accounts/env/logs are ignored and excluded from CI artifacts.

Earlier development-only viewport run reported a transient script syntax error while files were being changed. Fixed-build acceptance subsequently passed both languages with no page errors. The local production harness initially inherited development NODE_ENV; it now explicitly builds/starts Web in production while its API/local-chain mode remains development. Axe found primary-button contrast and an unnamed talent selector; both were corrected and rechecked. These earlier failures are not hidden or counted as passes.

## Open operational limits

A durable attestation recovery retries the same signed raw transaction while its result is uncertain. A definitively reverted/expired transaction stays ERROR; it is never reinterpreted as a failed submission or a passing proof. Long-outage/expiry recovery, external nonce contention and restore interruption must be exercised on the production worker before release. Ordinary contract deadline/dispute paths remain available; no unilateral refund or silent signing replacement was added.

Production Envio must provide a canonical live endpoint and a correct finalized cursor. Local RPC acceptance is explicitly `LOCAL_TEST_ONLY`; it does not close this gate. A clean checkout or green build does not close missing runtime gates. Do not announce production availability or begin gated P1 on the strength of this audit.

## Account access update — 2026-10-09

Google identity and wallet authority are separate. All participants must verify their wallet; guests never see account logout. Google name display comes from verified standard ID token claims, with separate hashed account sessions, origin checks, signature/audience/issuer/expiry checks and a one-use nonce. Wallet disconnection revokes wallet access; Google logout retains it. Legacy untouched “New member” placeholders receive guest names while custom profiles/history remain intact.

Real Google provider acceptance is **BLOCKED** without a project OAuth client ID and an authorized origin. Browser Google tests explicitly use a mocked provider; this is not counted as a real Google login. The real guest wallet signature/retry/switch/disconnect tests and cryptographic provider-token checks are executed locally.

Local preview startup exposed simultaneous development/build cache conflicts and an unclean PGlite shutdown. The API now handles normal termination and closes the database; the previous test database was preserved and the acceptance environment uses its own database. The first account test exposed active-query deletion leaving the network grid loading; cache reset/refetch corrected it. These failures were repaired before final acceptance.

One repeated local flow reached onchain completion before its Activity projection had caught up. Browser acceptance now waits up to 45 seconds for the actual indexed settlement and revision events, and still requires exactly one of each; it does not accept missing/duplicate records or manufacture events.
